#002 FaBo Starter Kit for Arduino

Overview

Arduinoで、FaBo Brickをちょっと使ってみたい！という方に、手軽にはじめられるキットです。

専用ケースに入れてお届けします。

Arduino本体は含まれません。別途、お買い求めください。

内容物一覧

ID Brick 数量
#101 LED Brick 5色のうち1個
#103 Button Brick 1個
#108 Temperature Brick 1個
#201 3Axis I2C Brick 1個
#307 BLE Nordic Serial Brick 1個
#402 ColorLED Ring Brick 1個
#501 OUT/IN Shield for Arduino 1個
#1301 3Pinケーブル 2本
#1302 4Pinケーブル 2本

LED Brickの色はお選びいただけません。

商品入替え、または販売中止などの理由により、予告なく内容物が変更される場合があります。
